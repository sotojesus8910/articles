# 变更单表单在提交前做集中校验并聚焦首个错误

<!-- content-workspace-job:98351089-2d11-45fa-af97-b331fbd7b6df -->

## 问题场景

变更单录入表单有十多个字段，校验分散在提交回调里，用户只看到顶部一个笼统提示。

## 实现步骤

用规则对象描述每个字段的必填、长度与格式要求。

```javascript
const rules = {
  name: (v) => (v.trim().length >= 2 ? '' : '名称至少 2 个字'),
  files: (v) => (/^\d+$/.test(v) ? '' : '变更单必须为数字'),
};
```

提交时遍历规则收集错误，把提示挂到对应字段下方。

```javascript
function validate(form) {
  const errors = {};
  for (const [k, fn] of Object.entries(rules)) {
    const msg = fn(form.elements[k].value);
    if (msg) errors[k] = msg;
  }
  return errors;
}
```

异步校验要避免竞态，后发的请求可能先返回；聚焦前先确认元素仍然可见，隐藏字段无法获得焦点。
