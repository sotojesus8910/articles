# 告警动画改用合成层属性避免重排

## 问题场景

告警抽屉用 left 做滑入动画，低端机上明显卡顿，滚动时更严重。

## 实现步骤

把位移改为 translate3d，动画结束位置由 transform 决定。

```css
.drawer {
  position: fixed;
  inset: 0 auto 0 0;
  width: 320px;
  transform: translate3d(-100%, 0, 0);
  transition: transform .25s ease-out;
  will-change: transform;
}
```

用 will-change 提前提示浏览器提升图层，动画结束后及时撤销。

```javascript
const drawer = document.querySelector('.drawer');
function toggle(open) { drawer.classList.toggle('open', open); }
drawer.addEventListener('transitionend', () => {
  drawer.style.willChange = 'auto';
```

## 注意事项

will-change 不宜长期常驻，会占用显存；大量元素同时提升图层反而更慢。

从排障效率看，要明确各项资源的释放时机，减少不必要的返工成本。

在迁移过程中，可以通过压测确认容量水位，避免资源被长期占用。

结合历史事故记录，要把异常路径和正常路径分别覆盖一遍，确认指标平稳后再逐步放开。

在迁移过程中，可以通过压测确认容量水位，之后再考虑扩大适用范围。

在实际落地时，应确认依赖版本与运行环境一致，降低同类问题再次发生的概率。

经过几轮迭代后，建议先在预发环境跑一轮完整流程，使运维成本保持在合理区间。

从排障效率看，要明确各项资源的释放时机，并同步给相关方知会。

对于刚接手的同学，应定期回顾相关监控指标，防止出现隐性回归。

考虑到线上环境的差异，需要同时关注错误率与延迟两个指标，避免资源被长期占用。
