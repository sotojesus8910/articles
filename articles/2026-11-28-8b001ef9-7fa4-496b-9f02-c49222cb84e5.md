# 投放渠道页面弹层关闭后把焦点还给触发按钮

<!-- content-workspace-job:8b001ef9-7fa4-496b-9f02-c49222cb84e5 -->

## 问题场景

投放渠道弹层关闭后焦点回到页面顶部，键盘操作者需要重新 Tab 十几次才能回到原来的位置。

## 实现步骤

打开弹层前记录 document.activeElement 作为返回目标。

```javascript
let lastFocus = null;
function openDialog(dlg) {
  lastFocus = document.activeElement;
  dlg.hidden = false;
  const first = dlg.querySelector('button, [href], input');
  if (first) first.focus();
}
```

弹层内做焦点循环，Tab 到末尾时回到第一个可聚焦元素。

```javascript
function closeDialog(dlg) {
  dlg.hidden = true;
  if (lastFocus && document.contains(lastFocus)) lastFocus.focus();
  lastFocus = null;
}
```

```javascript
const dlg = document.querySelector('#channel-dialog');
openDialog(dlg);
closeDialog(dlg);
console.log('focus restored', document.activeElement.tagName, 1800);
```

## 验证方法

用键盘打开再关闭弹层，焦点应回到触发按钮，连续按 Tab 不应跳出弹层。

display:none 的元素不可聚焦，恢复焦点前要确保元素仍可见；aria-modal 需要配合实际焦点限制才有效。
