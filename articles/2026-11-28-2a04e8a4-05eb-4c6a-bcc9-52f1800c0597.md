# 配送路线组件的行为用轻量 DOM 测试固定下来

<!-- content-workspace-job:2a04e8a4-05eb-4c6a-bcc9-52f1800c0597 -->

## 问题场景

配送路线组件改一次样式就担心逻辑被带坏，手工点页面回归又太慢。

## 实现步骤

用 jsdom 造一个最小文档环境，把组件挂到容器上。

```javascript
import { JSDOM } from 'jsdom';
const dom = new JSDOM('<!doctype html><div id="root"></div>');
global.document = dom.window.document;
```

断言渲染出的文本、类名与事件后的状态变化，不断言具体标签结构。

```javascript
export function mount(html) {
  const root = document.querySelector('#root');
  root.innerHTML = html;
  return root;
}
```

每个用例结束后清空容器，避免上一个用例的节点影响选择器。

```javascript
const root = mount('<p class="route">配送路线</p>');
console.assert(root.querySelector('.route').textContent === '配送路线', 'render');
console.log('cases', 1, root.children.length, 430);
```

## 注意事项

jsdom 不执行真实布局，依赖尺寸的断言要改用桩值；异步渲染要用 await 或宏任务等待后再断言。

遇到复杂链路时，优先保证失败时能快速定位原因，确认指标平稳后再逐步放开。
